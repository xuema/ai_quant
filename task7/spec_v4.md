# 超级顶底 V4 - 策略规则文档

---

## 1. 核心指标

```
RSV   = (CLOSE - LLV(LOW,27)) / (HHV(HIGH,27) - LLV(LOW,27)) × 100
SMA1  = SMA(RSV, 5, 1)          ← 通达信SMA: Y = (M/N)×X + (1-M/N)×Y_prev
SMA2  = SMA(SMA1, 3, 1)
趋势线 = 3 × SMA1 - 2 × SMA2    → 值域 ≈ 0~100

WR(42) = (HHV(HIGH,42) - CLOSE) / (HHV(HIGH,42) - LLV(LOW,42)) × 100
```

---

## 2. 买入规则

### 2.1 买入信号
趋势线 **上穿 11**（前一天 ≤ 11，今天 > 11）

### 2.2 买入过滤
| 条件 | 说明 |
|------|------|
| **量比 > 1.2** | 今天成交量 ÷ 过去10天平均成交量，必须放量20%以上 |
| **市值 ≥ 80亿** | 仅保留中大盘股，剔除小盘 |

**过滤失败直接淘汰，不进入评分。**

### 2.3 买入评分

```
评分 = 趋势线得分(0~100) + 量比加成(0~30)
```

| 因子 | 公式 | 满分条件 |
|------|------|---------|
| 趋势线得分 | `max(0, 100 × (1 - (趋势线 - 11) / 25))` | 趋势线 = 11.0（刚上穿，距11越近分越高） |
| 量比加成 | `min(30, (量比 - 1.2) × 30)` | 量比 ≥ 2.0（放量1倍），1.2倍时加0分 |

### 2.4 仓位管理

| 规则 | 详情 |
|------|------|
| **固定持仓数** | 5只 |
| **仓位分配** | 均分（每只20%资金） |
| **补仓机制** | 有空位 → 按评分从高到低补入 |
| **不主动换仓** | 持仓股无卖出信号则继续持有，不被新信号替换 |

## 3. 卖出策略（3重机制，优先级从高到低）

| # | 类型 | 触发条件 | 含义 |
|---|------|---------|------|
| ① | **ATR动态止损** | 当前价 < 持仓最高价 - 2×ATR(14) | 防止大幅回撤，最优先 |
| ② | **WR高位止盈** | WR(42) > 45 **且** 趋势线 > 50 | 未到89但已从高位明显回落时提前卖出 |
| ③ | **趋势线信号卖出** | 趋势线下穿89（前一天 ≥ 89，今天 < 89） | 经典顶部确认卖出 |

### 3.1 ATR止损细节

```
ATR(14) = 近14日真实波动范围平均值
持仓最高价 = 从买入以来的最高收盘价
止损线 = 持仓最高价 - 2 × ATR(14)
```
每天更新持仓最高价，止损线自动跟随上移（trailing stop）。

### 3.2 WR止盈细节

**为什么需要"趋势线 > 50"这个额外条件？**

防止刚买入就被踢出——刚买入时趋势线才11左右，但WR可能高达80（因为刚从底部反弹）。只有趋势线进入高位区（>50），WR>45才是真正的高位回落。

### 3.3 WR值参考

| WR值 | 含义 |
|------|------|
| 0~10 | 接近42天最高，极强 → 持有 |
| 30~40 | 轻微松动，正常波动 → 持有 |
| **>45** | 已回落到区间中下部 → 配合趋势线>50 → 卖出 |
| 80~100 | 接近42天最低，大跌 → ATR已先触发 |

## 4. 每日执行流程

```
[ before_market_open ]
  全A股 → 剔除ST → 市值≥80亿 → 更新候选池

[ market_open ]
  1. 遍历持仓 → 检查ATR止损 + WR止盈 → 触发则清仓
  2. 扫描全市场 → 产出买入列表 + 信号卖出列表
  3. 执行信号卖出（下穿89）
  4. 计算空位 = 5 - 当前持仓数
  5. 空位 > 0 → 买入评分前N只（均仓）

[ after_market_close ]
  打印持仓数量、总资产、可用现金
```

## 6. 策略逻辑图

```
每日开盘
  │
  ├─ [ATR检查] 当前价 < 最高价 - 2×ATR ?
  │      ├─ 是 → 🛑 清仓
  │      └─ 否 → 继续
  │
  ├─ [WR检查] WR(42) > 45 且 趋势线 > 50 ?
  │      ├─ 是 → 📉 提前止盈
  │      └─ 否 → 继续
  │
  ├─ [信号扫描]
  │      ├─ 趋势线下穿89 → 🔴 信号卖出 → 清仓
  │      └─ 趋势线上穿11 + 量比>1.2 → 进入评分池
  │
  ├─ [补仓] 空位 = 5 - 持仓数
  │      ├─ 空位 > 0 → 从评分池取Top N → 均仓买入
  │      └─ 空位 = 0 → 跳过
  │
  └─ [收盘汇总] 打印持仓/净值/现金
```
